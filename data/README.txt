The five 1000 Genomes regions used in the SwiftLD preprint (about 4.7 MB in all, sha256-pinned in gen_data.py).

Source: the 1000 Genomes Project Phase 3 release (The 1000 Genomes Project Consortium, "A global reference for
human genetic variation", Nature 526:68-74, 2015), openly available without restriction under the IGSR data reuse
policy (https://www.internationalgenome.org).

  VCF:   http://ftp.1000genomes.ebi.ac.uk/vol1/ftp/release/20130502/ALL.chr22.phase3_shapeit2_mvncall_integrated_v5b.20130502.genotypes.vcf.gz
  Panel: http://ftp.1000genomes.ebi.ac.uk/vol1/ftp/release/20130502/integrated_call_samples_v3.20130502.ALL.panel
  Build: GRCh37; phased with SHAPEIT2; 2,504 samples. Retrieved on 11 October 2026.

Every record in each region is kept: SNPs, indels and multi-allelic sites, with the original INFO. No site
filtering is applied here; the benchmark command applies --maf inside the tool.

"stripped": every '|' in the genotype columns was replaced by '/' to make an unphased set for --geno-r2.
The rh_ sets are the holdout sets (evaluate.py --holdout).

To rebuild them from the release:
  python3 data/tools/fetch_1kg_chr22_head.py 19800000 1kg
  python3 data/tools/make_real_data.py 1kg/chr22_head.vcf.gz 1kg/integrated_call_samples_v3.20130502.ALL.panel OUT_DIR

The synthetic benchmark sets are generated by gen_data.py from fixed seeds when prepare.py runs.
